About

From native iOS to leading React Native teams

I started out writing native iOS apps in Swift and Objective-C: a QR scanner, a background voice recorder, an enterprise fax tool. That grounding still pays off. When a React Native screen drops frames or a Bluetooth connection keeps falling over, I'm comfortable going down into the Swift or Kotlin layer to find out why.

These days I lead React Native teams. A lot of my time goes into the parts users never see: app architecture, state management, offline sync for people on bad connections, and a shared component library so iOS and Android get the same features in the same release. I also review a lot of code and mentor junior and mid-level developers.

Lately I use AI in two places. Inside apps, that means on-device ML with ML Kit and Vision Camera, and LLM features with the Gemini API. In my own work, Claude Code, Cursor and Copilot take care of the repetitive parts of refactoring and writing tests.
